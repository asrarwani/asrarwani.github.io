# asrarwani.github.io
My personal site — part résumé, part "here's who I actually am." Built from scratch, no template.
→ Live at asrarwani.github.io
What's here
A one-page site covering the professional side (business development background, experience, what I bring) and the human side — the films I rewatch, what's in my ears, the books on my shelf, and the people who put up with me. There's also a small interactive terminal for the curious. Type help.
Run it locally
It's a single self-contained index.html — no build step, no dependencies. Either:
bash# just open the file
open index.html

# or serve it (so paths behave exactly like production)
python3 -m http.server 8000
# then visit http://localhost:8000
Tech
Plain HTML, CSS, and a sprinkle of vanilla JavaScript. Fonts load from Google Fonts. Hosted on GitHub Pages.
